# 2026-08-20 周期报告与终点动作迭代复盘

## 1. 本轮目标

本轮把“高危 URL 触发一次测试”升级为可持续复盘的周期测试能力，同时明确首批路径用例的执行策略：

1. 报告使用 Vben Admin 的信息结构和 Ant Design Vue 组件。
2. 使用 ECharts 展示同一 URL 在多个周期内的变化。
3. 报告同时回答测试预期、本次结果、历史平均和具体问题。
4. `Root -> Leaf` 路径中的中间页面只负责到达，压力动作集中在终点页面。
5. 首批终点动作覆盖上下滑动和返回再进入两类稳定性场景。

## 2. 已完成能力

### 2.1 周期测试报告

报告主体采用以下 Ant Design Vue 组件：

- `Card`：承载独立报告模块。
- `Statistic`：展示预警 URL、图谱匹配、即时用例和通过率。
- `Table`：展示指标、测试预期、本次结果、历史平均和问题。
- `Tag`：表达通过、观察和异常状态。
- `Segmented`：切换周期趋势指标。

ECharts 趋势图支持：

- 通过率。
- 平均 FPS。
- 平均功耗。
- 异常数量。
- 近 12 个测试周期。
- 指标阈值线。
- 越过阈值的红色数据点。
- Hover 查看周期、执行次数和异常数量。

### 2.2 多次测试的表达方式

同一个 URL 不再只有一个最终状态，而是包含：

```text
URL 聚合报告
  -> 周期趋势
  -> 单次执行结果
  -> 指标对比
  -> 脚本步骤证据
```

报告表格的阅读顺序固定为：

| 字段 | 回答的问题 |
|---|---|
| 测试预期 | 什么范围算通过 |
| 本次结果 | 这次实际测到什么 |
| 历史平均 | 正常周期通常是什么水平 |
| 问题 | 本次相对历史平均偏离多少 |

### 2.3 首批路径用例

每条 `Root -> Leaf` 路径生成两个变体：

```text
变体 A：到达终点 -> 向上滑动 4 次 -> 向下滑动 3 次 -> 汇总指标
变体 B：到达终点 -> 返回上一页 -> 从原入口重新进入 -> 重复 3 次 -> 汇总指标
```

共同规则：

- 中间页面只执行导航和页面校验。
- 路径恢复耗时不进入性能结果。
- 终点页面稳定后再开启采集窗口。
- 终点动作执行过程中持续采集。
- 任一步页面校验失败，该次结果标记为无效或执行失败。

当前 QQ Mock 有约 220 条叶子路径，因此生成 440 条首批路径用例。该数量是策略结果，不是重复数据。

## 3. 工程实现

### 前端

```text
TestReportDashboard.vue
  -> AntDV 统计卡和结果表
  -> PerformanceTrendChart.vue
     -> ECharts 周期趋势与阈值线

testCases.js
  -> Root-to-Leaf 路径枚举
  -> scrollLoop / backForwardLoop 两个终点变体
```

### 后端

```text
TestCaseService.generate()
  -> 枚举叶子路径
  -> 每条路径持久化两个 terminalPath 用例
  -> scriptTask 输出终点动作参数
```

关键字段：

```json
{
  "phase": "terminalActions",
  "terminalPattern": "scrollLoop",
  "startAfterFinalPageStable": true
}
```

## 4. 本轮问题与处理

### G6 Minimap 生命周期

从图谱切换到测试报告时，Minimap 存在 128ms 尾随渲染。图实例提前销毁会导致回调读取空模型。

处理方式：先解绑 Minimap 事件，等待尾随回调排空，再销毁图实例。切换报告后控制台已无错误。

### 报告信息过度装饰

早期报告使用大面积蓝色渐变和自定义流程块，与 Vben Admin 主体割裂。本轮改为白色平面卡片、灰色页面背景和 AntDV 原生组件，并删除“端到端执行链”展示。
